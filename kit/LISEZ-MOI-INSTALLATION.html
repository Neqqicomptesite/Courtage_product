ODDO Séquences

Campagnes de prospection par email, avec relances automatiques qui s'arrêtent dès qu'on vous répond. L'application tourne sur votre PC : vos contacts et vos emails restent chez vous.

1Installer Python (une seule fois)

  1. Téléchargez Python 3.12 sur python.org/downloads.
  2. Dans la première fenêtre de l'installateur, cochez « Add python.exe to PATH », puis « Install Now ».

2Installer l'application

  1. Décompressez ce dossier ODDO-Sequences où vous voulez (par exemple dans Documents).
  2. Double-cliquez sur start.bat. La première fois, l'installation prend quelques minutes (connexion internet nécessaire).
  3. Votre navigateur s'ouvre sur http://127.0.0.1:8765 : c'est l'application. Ajoutez-la à vos favoris.
  4. Une fenêtre noire reste ouverte : c'est le moteur d'envoi. La fermer arrête les envois ; réduisez-la simplement.

3Connecter votre boîte mail

Dans l'application : Réglages → Boîte mail d'envoi. Les informations se trouvent dans le cPanel : E-mail → Comptes de messagerie → votre adresse → « Connecter des appareils », colonne « SSL/TLS ».

Envoi (SMTP)serveur « sortant », port 465, SSL
Lecture (IMAP)serveur « entrant », port 993
Identifianten général votre adresse complète

Cliquez sur Tester la connexion (un email de test arrive chez vous), vérifiez le dossier « Envoyés », ajoutez votre signature, puis Enregistrez. Le mot de passe est rangé dans le coffre-fort de Windows, jamais dans un fichier.

4Ce qui est déjà prêt

  • Entreprises : les compagnies partenaires, avec leur logo et leurs interlocuteurs par service.
  • Séquences : 11 modèles rédigés (prospection, gestion, souscription) et les textes par fonction et par secteur.
  • Guide (en bas du menu) : « Bien démarrer », le tour des écrans, les bons réflexes. Commencez par là.

5Toujours commencer en mode test

Au départ, le mode test est activé (badge orange en haut) : chaque email part vers votre propre adresse, avec l'objet [TEST → destinataire].

  1. Contacts → Nouveau contact avec votre propre adresse.
  2. Séquences → Gestion → G6 → Envoyer → choisissez-vous → « Personnaliser d'abord » → remplacez les [crochets] → Envoyer.
  3. Relisez l'email reçu. Puis seulement : Réglages → Mode test → désactiver (tapez REEL pour confirmer).

Jamais d'essai sur un vrai contact : ses relances encore prévues partiraient pour de vrai après le passage en mode réel.

6Vos prospects

Contacts → Importer → Télécharger le modèle Excel : remplissez-le (listes déroulantes), puis importez-le. Pour écrire à un groupe : Campagnes → Nouvelle campagne ; à une ou quelques personnes : Envoyer sur une séquence.

7Les bonnes pratiques

  • Nous envoyons tous depuis le même domaine oddo.ma : gardez les plafonds prévus (25 emails par jour, 10 par heure). Trop d'envois ou de rebonds pénalisent tout le monde.
  • Chacun a sa propre application : elle ne voit pas les envois des collègues. Répartissez-vous les prospects : deux personnes ne prospectent pas la même entreprise.
  • Seuls les prospects reçoivent de la prospection ; clients, assureurs et partenaires peuvent recevoir les séquences de gestion et de souscription.
  • L'application n'envoie rien quand le PC est éteint ou en veille ; elle rattrape le retard au redémarrage, un email à la fois.
  • Une sauvegarde de vos données est faite à chaque démarrage, dans data\backups. Ne supprimez jamais le dossier data.
  • Mises à jour : l'application les cherche seule. Quand une nouvelle version est prête, la cloche le signale : Réglages → Mise à jour → Installer et redémarrer. Vos données ne bougent pas.
